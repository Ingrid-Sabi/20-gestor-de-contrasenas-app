# 20 · Gestor de contraseñas — App móvil

> Bóveda local cifrada con biometría, generador de contraseñas y copiado temporal al portapapeles.

Aplicación móvil en Expo + React Native + TypeScript + Expo Router con SQLite local cifrado y sincronización opcional con `20-gestor-de-contrasenas-api`.

## Requisitos
- Node.js 20+
- Expo Go o emulador Android/iOS
- Variable pública en `.env`: `EXPO_PUBLIC_API_URL=https://20-gestor-de-contrasenas-api.vercel.app`

## Comandos
```bash
npm install
npx expo start
npm run check
```
